# Kairos Pine v6

## How to paste into TradingView (read this)

The broken editor tab named "Kairos Tape 08202026" is a truncated 175-line paste. Do not keep fixing that file.

1. Open the RAW file: https://raw.githubusercontent.com/Fiasco1023/kairos-pine/main/kairos-tape.pine
2. Ctrl+A, Ctrl+C
3. In TradingView: Pine Editor -> Open -> New indicator (blank)
4. Ctrl+A, Ctrl+V into the BLANK script
5. You must see about 250 lines and the text `ta.dmi`
6. Save, then Add to chart
